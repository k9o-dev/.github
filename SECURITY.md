# Security policy

## Report a vulnerability

Please do not report security problems in a public issue.

Email help@kilimanjaro.dev with the subject "Security" and include:

- what you found, and which package and version it affects
- the steps to reproduce it
- any proof of concept you have

We will acknowledge your report and keep you informed while we work on a fix.

## Supported versions

We fix security issues in the latest release of each SDK. Please upgrade to the latest version before you report.
