# Contributing to Kilimanjaro

Thank you for using Kilimanjaro. This page explains how to report problems and suggest changes.

## How these repositories work

- Each SDK repository is published from our monorepo and replaced with every release, so its history is one commit per release.
- Because the repositories are generated, we cannot merge pull requests into them directly.

## Report a bug

Open an issue on the repository for your language and include:

- the SDK version and your language or runtime version
- the smallest code that reproduces the problem
- the full error, including its `code` and request id if there is one

## Suggest a change

Open an issue that says what you want to do and why. If you already have a fix, link a pull request as a reference. We apply accepted changes in the monorepo, and they appear in the next release.

## Security issues

Do not open a public issue. See [SECURITY](https://github.com/k9o-dev/.github/blob/main/SECURITY.md).
